# Dissertation-project--JNU-New-Delhi-
This repository corresponds to my MSc Bioinformatics thesis titled "Profiling of Circular RNAs in OSCC Using Bioinformatics Pipeline". The study aims to identify and quantify circRNAs using CIRI2 and  CIRIquant from RNA-Seq data derived from Oral Squamous Cell Carcinoma samples and matched controls.
